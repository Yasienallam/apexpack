# Apex Pack | Confidential business analytics — fictional portfolio demo

**Real-world business context; fictional demo records only.** This public repository does **not** include actual Apex Pack customer identities, sales figures, financial statements, or original operational workbooks. Do not interpret fictional examples as company performance.

Business analytics questions:
- How can sales and cash collections be analyzed independently?
- How can account-ledger balances be reconciled to sales less receipts?
- Which product families have higher *gross* margin?
- Which transactions should be reviewed due to quality flags?

This minimal demonstration is intentionally restricted to synthetic records. It is not an audit of actual books and does not assert a verified company net profit.

Run `python demo.py` with Python 3.10+ (standard library only). Private full analytics with workbook ingestion and local-only Streamlit dashboard is maintained in a **separate private repository**.

Do not put sensitive data, screenshots, or workbook exports in this public project.
